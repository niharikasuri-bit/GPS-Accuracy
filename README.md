# GPS Accuracy – Capturing location popup

Compact mobile popup for a mandatory GPS capture: the user waits until accuracy is 10 m or less before saving. Accuracy changes colour as the user moves:

- **Red** – more than 10 m (Low accuracy)
- **Amber** – 5 to 10 m (Fair accuracy, Save enabled)
- **Green** – 5 m or less (Good accuracy, Save enabled, best)

Single `index.html` with a demo panel to simulate accuracy. Open it in a browser, or see the live link on GitHub Pages.
